Fragmento de CSS

  • Elemento: la tarjeta de cristal de DAYLOG
  • Selector: una clase, .tarjeta-cristal, reutilizable
  • Se aplica a: el <div> que envuelve el campo de motivo
  • backdrop-filter desenfoca el fondo y crea el efecto cristal
  • border-radius y box-shadow copian las esquinas y la sombra de Figma
.tarjeta-cristal {
  background: rgba(255, 255, 255, 0.82);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.9);
  border-radius: 40px;
  padding: 1rem 2rem;
  box-shadow: 0 8px 24px rgba(43, 34, 51, 0.18);
}
